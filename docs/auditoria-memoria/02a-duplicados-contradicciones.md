## Reglas ambiguas (no accionables)

- **`~/.claude/CLAUDE.md`, sección "Privacidad y secretos": "Cliente UE = anonimizar por defecto."** No dice qué operación cuenta como anonimizar (¿iniciales?, ¿omitir el nombre de la empresa?, ¿solo en logs o también en el propio deliverable, que necesita el nombre real de ESE cliente para tener sentido?), ni cuándo se aplica exactamente. Reformulación accionable: "En logs, chats internos y capturas que puedan salir de la sesión: sustituye nombre completo de personas de clientes UE por iniciales + rol (ej. 'D. de Hemmersbach'). Nunca en el deliverable final dirigido a ese mismo cliente, donde el nombre real es necesario."
- **`~/.claude/CLAUDE.md`, sección "Cómo prefiero comunicarme": "Si te equivocas, reconócelo sin disculpas excesivas."** "Excesivas" no tiene umbral. Reformulación: "Reconoce el error en una frase ('me equivoqué, era X'), sin repetir 'lo siento' más de una vez ni justificar el porqué salvo que Max pregunte."
- **`MEMORY.md`, inbox: "⛔ Ejemplos dentro de reglas para LLM = solo estructura, nunca léxico"** (origen: sesión Hemmersbach 21-08). Esta línea SÍ se inyecta completa (es MEMORY.md), pero fuera del contexto de la sesión que la generó es un acertijo: no dice qué es "estructura" ni qué es "léxico" en un prompt. Reformulación: "Cuando un ejemplo dentro de un system prompt para un LLM ilustre un patrón de respuesta, usa marcadores genéricos para el contenido variable (`[producto]`, `[nombre]`) y nunca palabras reales del dominio (nombres de producto, frases del cliente): el modelo copia el vocabulario literal del ejemplo en vez de aprender solo la forma."
- **`MEMORY.md`, inbox: "🔜 [Hemmersbach 25-08: el historial de info@ llega al modelo y 10 borradores reales reemplazados] · ⛔ reproplan; timeouts al 9%; rotar API key n8n"** — la lista de "pendientes" tras el `·` (reproplan, timeouts al 9%, rotar key) son fragmentos sin verbo ni sujeto: no se puede saber, sin abrir el session-log citado, si "reproplan" es algo que hacer, algo que ya se hizo, o el nombre de un artefacto. Reformulación mínima: cada pendiente del inbox necesita un verbo en infinitivo ("rotar la API key de n8n de Hemmersbach por los timeouts del 9%").
